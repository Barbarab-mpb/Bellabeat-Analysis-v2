
## **Title**: Product Analysis for Bellabeat, A Wellness Technology Company

## **Executive Summary**
Using Excel, R and Tableau, I pulled data from a Kaggle database and created charts and a dashboard highlighting patterns in user’s behaviors. I made the following recommendations based on findings that identified variations in activity levels and sleep patterns by day of week:
* Developing physical activity of varying length and intensity based on user’s abilities and goals.
* Sending out weekly alerts to remind users that even light activity burn calories and acknowledging small victories that users achieve. 
* Helping users create sleep routines that encourage them to increase their time in bed which the data shows increase their time asleep.

## **Business Problem**
There are numerous fitness devices being marketed so for a  company like Bellabeat to grow into a larger player in the global market they need to determine how customers use devices and which device features help customers improve their health. How can Bellabeat improve their marketing strategy by identifying which features such as  personalization, insights that help users set goals, ability to monitor progress, and improve accountability would make devices more attractive to users and how can Bellabeat devices be altered to make them more competitive in the global market?

## **Methodology**
* R: extract, clean, transform, and analyze data. Summarize finding using data visualization.
* Tableau: created dashboards to highlight patterns.

## **Skills**
* R Studio: writing scripts to merge tables, summarize data, using ggplot2 for data visualization.
* Tableau: developing  dashboard to show patters in the data.

## **Recommendations**
The analysis found that most users were not physically active but even light physical activity can help users burn calories. Users were more active during certain days of the week as compared with other day. I recommend that Bellabeat:
* Help users create a fitness plan targeted to their level of fitness and goals.
* Help to motivate users by sending applauds when they are doing well and when they not doing as well, reminders that even light activity can be beneficial.
* Provide a support system for users by creating community/group activities.
* Provide holistic health analysis (heart health, sleep, diet, and stress analyses).

## **Next Steps**
* Collect data from larger, more representative population.
* Collect user’s demographic information (age, sex, current activity level, etc.).
* Collect data on the fitness goals of users.
